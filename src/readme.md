# Eruda DevTools for Acode

> A mobile in-app DevTools overlay for Acode that lets you inspect DOM elements, view console logs, monitor network activity, and debug your environment directly on your device.

![Version](https://img.shields.io/badge/version-v1.0.0-blue)
![License](https://img.shields.io/badge/license-Apache--2.0-green)
![Status](https://img.shields.io/badge/status-Active-success)

---

## ✨ Features

- 🛠 **Floating Action Button:** Draggable entry button accessible anywhere across the editor and menus.
- 📜 **Console Inspector:** Capture and display `console.log`, `console.warn`, `console.error`, and `console.table` outputs in real-time.
- 🔍 **DOM Elements Viewer:** Inspect, touch-select, and view the DOM tree hierarchy with computed CSS properties.
- 🌐 **Network Monitor:** Track and inspect all `XMLHttpRequest` (XHR) and `fetch` requests with headers and payloads.
- 💾 **Storage & Resources:** View and manage `localStorage`, `sessionStorage`, cookies, and loaded scripts.
- 🌓 **Theme Synchronization:** Automatically adapts to Acode's Dark or Light theme.
- ⚡ **Offline Ready:** Packaged with local Eruda scripts, with automatic fallback to CDN if needed.

## 📦 Installation

1. Open **Acode**.
2. Navigate to **Settings** > **Plugins**.
3. Search for **Eruda**.
4. Click **Install**.

---

## ⚙️ Configuration

You can enable or disable the floating DevTools icon from the plugin settings:

1. Open **Settings** > **Plugin Settings**.
2. Select **Eruda**.
3. Toggle:
   - **Enable Eruda Floating DevTools:** Turn on to show the floating entry button; turn off to hide and unmount.

---

## 🚀 How to Use

1. Enable the plugin via **Settings > Plugin Settings > Eruda**.
2. A floating **Gear/DevTools icon** will appear in the bottom corner of your screen.
3. **Tap** the floating icon to open the full Eruda DevTools panel.
4. **Drag** the floating icon to move it to any convenient spot on your screen.
5. Use the tabs (*Console*, *Elements*, *Network*, *Resources*, *Info*) to inspect the app.
6. Tap the close/minimize button inside the panel to collapse it back into the floating icon.
